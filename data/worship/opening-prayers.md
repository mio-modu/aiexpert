# 주일예배 시작 기도문 아카이브

예배 시작 기도(1분 기준) 데이터 누적 파일.
낭독 기준: **1분 ≈ 330~400자**

## 메타 규칙

- 각 기도문은 `ID / 유형 / 길이 / 문체 / 성구 / 사용이력 / 평가` 를 갖는다.
- 유형: `임재` `말씀` `통합` `회개` `감사` `절기`
- 문체: `정통`(하옵소서) / `현대`(해 주세요)
- 평가: `좋음` `보통` `교체`
- 최근 8주 내 사용된 성구·핵심표현은 재사용을 피한다.

## 5블록 생성 공식

| 블록 | 분량 | 역할 | 교체 변수 |
|---|---|---|---|
| ① 호칭 | 1줄 | 하나님의 속성 선언 | 거룩하신 / 살아계신 / 좋으신 / 은혜와 진리가 충만하신 / 신실하신 |
| ② 감사 | 2~3줄 | 지난 한 주 돌아봄 | 보호 / 인도 / 호흡 / 공동체 / 절기 |

| ④ 말씀 간구 | 3~4줄 | 전하는 자 + 듣는 자 | 히4:12 / 고전2:4 / 마13:8 / 살전2:13 / 사55:11 |

- 찬양의 핵심 단어를 기도문에 그대로 옮기기 (예: "햇살", "송축해")
